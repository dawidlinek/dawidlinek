<summary><b>epftoolbox2</b> · electricity price forecasting library, published on PyPI</summary>
<br/>

<img src="./assets/projects/epftoolbox2.jpg" alt="epftoolbox2 capabilities" width="62%"/>

A complete rewrite of the academic
[epftoolbox](https://github.com/jeslago/epftoolbox), rebuilt as composable
pipelines rather than scripts. Data sources for ENTSO-E, Open-Meteo and
calendar features, plus transformers, validators, models, evaluators and
exporters that assemble into data and model pipelines defined in YAML, so an
experiment can be saved, reloaded and rerun. Built-in request caching and
process-based parallelism.

[Read more](https://linek.dev/project/epf-toolbox-2) ·
[PyPI](https://pypi.org/project/epftoolbox2/) ·
[Repository](https://github.com/dawidlinek/epftoolbox2) ·
[Documentation](https://dawidlinek.github.io/epftoolbox2/)

</details>
